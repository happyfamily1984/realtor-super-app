# 중개사 슈퍼앱 (초안)

공인중개사 사무소 업무를 한곳에서 처리하는 모바일 웹앱(PWA)입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드 (dist/)
```

## 무엇을 하는 앱인가

사무소의 실제 업무(손님, 매물, 계약)를 관리합니다. 시세 정리·뉴스·카드뉴스·오픈톡방용 자료 같은 정보성 기능은 이 앱에서 빼고 알리미 앱으로 옮겼습니다.

## 하단 5단 메뉴

| 메뉴 | 내용 |
| --- | --- |
| 홈 | 신규 상담·진행 매물·진행 계약 수, 읽지 않은 채팅과 새로 접수된 매물, 다가오는 일정 |
| 손님 | 상담 신청(손님 장부), 손님용 앱에서 온 채팅, 맞춤 매물 추천과 제안서(이미지·PPT) |
| 매물 | **내 매물**(매물장: 등록·상태·소유자·사진·네이버 매물번호·메모), **손님 접수**(손님이 내놓은 매물을 내 매물로 등록), **네이버 수집**(확장 프로그램으로 모은 시장 매물, 내 매물 중복 광고 확인) |
| 계약 | 계약 등록, 계약서 작성·인쇄, 중도금·잔금 일정(D-day), 계약서 사진 보관과 AI 정리 |
| 더보기 | 사무소 설정(계약서에 들어가는 정보 포함), 손님용 앱 주소·소식 올리기, 자료 백업·복원 |

- 내 매물에서 **계약 등록**을 누르면 그 매물 내용이 계약과 계약서에 미리 채워집니다.
- **계약서 작성**은 매매·전세·월세를 지원합니다 (`src/lib/contractDoc.ts`). 일반 서식의 틀을 따른 초안이므로 서명 전에 협회 서식·최신 법령과 대조해야 합니다. 주민등록번호는 저장하지 않고 인쇄 후 직접 적습니다.
- 맞춤 추천은 진행 중인 내 매물에서 고르고, 원하면 네이버 수집 매물도 함께 봅니다.
- 손님 상담·내 매물·계약은 기기 안에 저장됩니다. 더보기에서 백업 파일로 내보내고 복원할 수 있습니다. 내 매물 사진과 채팅·손님 접수 매물은 서버에 있습니다.

## 두 개의 앱

| 앱 | 주소 | 쓰는 사람 |
| --- | --- | --- |
| 중개사 슈퍼앱 | `/` (index.html) | 사무소 |
| 손님용 앱 | `/customer.html` | 손님 (홈 화면에 추가하거나 `android/` 의 APK 로 설치) |

손님용 앱 메뉴: **소식**(사무소가 올린 소식) · **실거래**(안양시 동안구 아파트·오피스텔을 골라 새 실거래 알림) · **매물 내놓기** · **상담**(채팅)

메인 단지 목록은 매일 받는 네이버 매물 자료에 든 단지를 씁니다 (아래 "다른 저장소와의 관계").

## 서버 기능 (Vercel)

`api/` 폴더가 Vercel Functions 로 배포됩니다.

| 설정 | 내용 |
| --- | --- |
| Storage > Upstash Redis | (필수) 채팅, 손님 접수 매물, 소식, 사진, 알림 구독 저장 |
| `APP_PASSCODE` | (권장) 사무소용 기능 접속 암호. 앱의 더보기 > 사무소 설정에 같은 암호 입력 |
| `GEMINI_API_KEYS` | 계약서 AI 정리, 네이버 매물 캡처 정리에 사용. 쉼표로 여러 개 넣으면 한도가 끝난 키는 건너뜀 |
| `GEMINI_MODELS` | (선택) 쉼표로 구분한 모델 순서 |
| `MOLIT_SERVICE_KEY` | 손님용 앱의 실거래 알림에 사용 (아파트·오피스텔 매매) |
| `CRON_SECRET` | (권장) 하루 한 번 실거래 알림 작업 보호 |

| 주소 | 내용 |
| --- | --- |
| `/api/office` | 사무소용: 받은 채팅·접수 매물, 소식 올리기, 사진 올리기 (접속 암호 필요) |
| `/api/c` | 손님용 앱: 소식, 관심 단지, 매물 접수, 채팅, 알림 구독 |
| `/api/ai` | `task`: `contract`(계약서 사진 정리) · `listings`(매물 캡처·글 정리) |
| `/api/cron` | 하루 한 번: 새 실거래를 찾아 관심 단지로 지정한 손님에게 알림 |
| `/api/img` | 저장된 사진 |

로컬에서는 `.env.local` 에 같은 변수를 넣고 `npm run dev` 하면 `/api` 도 함께 동작합니다 (저장소가 없으면 메모리에 임시 저장).

## 네이버 매물 수집

서버가 네이버를 자동으로 긁지 않습니다. 사용자가 보고 있는 화면에서 가져옵니다 (매물 > 네이버 수집 > 가져오기).

- **PC 크롬 확장 프로그램** (`extension/`): 시군구 코드와 동 이름을 넣으면 그 동 화면으로 이동해 매물을 모으고, 앱 창을 열면 자동으로 들어옵니다.
- **북마클릿·캡처·복사**: 화면에 뜬 매물을 파일로 저장하거나, 캡처·복사한 글을 AI가 정리합니다.
- 다시 수집하면 신규·가격 변동·사라진 매물을 표시합니다.
- **내 매물 중복 광고**: 내 매물에 적어 둔 네이버 매물번호나 사무소 이름으로 우리 광고를 알아보고, 동·면적·층이 같은 다른 중개사무소 광고를 알려 줍니다.

## 손님용 APK

`android/` 는 배포된 손님용 웹앱을 전체 화면 앱으로 여는 안드로이드 프로젝트(TWA)입니다.

```bash
cd android && ./build.sh <배포 주소> <서명 키 파일> <암호> [버전 번호]
```

서명 키 파일은 저장소에 올리지 말고 따로 보관하세요. 같은 키로 서명해야 업데이트 설치가 됩니다.

## 구조

- `src/App.tsx` — 하단 메뉴, 종료 확인
- `src/pages/` — Home, Consult(손님), Properties(매물), Listings(네이버 수집), Inbox(채팅·접수), Contracts, ContractDocSheet, More
- `src/customer/` — 손님용 앱
- `src/data/` — 자료 형식 (property 내 매물, intake 접수 양식, sample 상담·계약·설정, main 메인 단지)
- `src/lib/nav.ts` — 뒤로가기 규칙 (창·선택 모드 취소 → 이전 화면 → 홈에서 종료 확인)
- `src/lib/contractDoc.ts` — 계약서 초안, `src/lib/proposal.ts` · `design.ts` — 제안서, `src/lib/naverUpload.ts` — 네이버 등록 초안
- `api/` — 서버 기능

## 기기를 바꿀 때

손님 상담·내 매물·계약·계약서 사진·설정은 기기(브라우저) 안에 저장됩니다. 서버로 옮겨지지 않습니다.

1. 옛 기기: 더보기 > 자료 백업 > **백업 파일 저장** (계약서 사진 포함)
2. 백업 파일을 새 기기로 옮김
3. 새 기기: 정식 주소를 열고 더보기 > **백업에서 복원**
4. 새 기기: 더보기 > 사무소 설정에서 접속 암호 확인, 손님 탭에서 **알림 켜기** 다시 누르기 (알림은 기기마다 따로 켭니다)

채팅, 손님 접수 매물, 내 매물 사진, 손님에게 올린 소식은 서버에 있어 그대로 보입니다.

## 손님용 APK 서명 키

손님용 APK를 업데이트하려면 처음 만든 것과 **같은 서명 키**(`customer.keystore`, 별칭 `customer`)가 필요합니다.
서명 키와 암호는 저장소에 두지 않습니다. 사용자가 따로 보관합니다. 새 작업 환경에서 APK를 다시 만들 때는 그 파일과 암호를 받아 `android/build.sh` 에 넘깁니다.
안드로이드 SDK 가 없는 환경이면 먼저 설치해야 합니다 (명령줄 도구 + `platforms;android-35`, `build-tools;35.0.0`).

## 다른 저장소와의 관계

시세 정리·뉴스·보고서 같은 정보성 기능과 메인 단지 자료 수집기는 뉴스파인더 저장소(`real-estate-news-finder`)가 맡습니다. 이 저장소에는 수집기가 없습니다.

이 앱은 그쪽 수집 결과 중 매일 받는 네이버 매물만 읽습니다 (`src/lib/naverDaily.ts`).

- 메인 단지 목록 (손님용 앱의 추천 단지, 네이버 수집 매물의 메인 단지 보기)
- 내 매물과 비슷한 광고 확인: 같은 단지에서 거래 종류·면적·동·층·가격이 비슷한 광고를 찾아 보여 주고, 새로 올라온 것만 알립니다. 호수가 나오지 않아 같은 집이라고 단정할 수는 없습니다.
