# 중개사 슈퍼앱 (초안)

공인중개사 사무소 업무를 한곳에서 처리하는 모바일 웹앱(PWA)입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드 (dist/)
```

## 하단 5단 메뉴

| 메뉴 | 내용 |
| --- | --- |
| 홈 | 오늘 요약, 바로가기, 다가오는 일정, 사무소·지역 설정 |
| 브리핑 | 국토부 실거래 + 지역 뉴스, AI 분석, 카드뉴스(1080×1350 PNG) 생성·저장·공유 |
| 매물 | 매물 가져오기(캡처·복사한 글을 AI가 정리), 필터, 단지별 평균가·면적별 분포 차트 |
| 상담 | 상담 신청서 접수·상태 관리, 맞춤 매물 추천, 제안서(이미지·PPT) 생성 |
| 계약 | 계약·중도금·잔금 일정(D-day), 계약서 사진 보관, AI 계약서 정리, 알림 |

## 서버 기능 (Vercel)

`api/` 폴더가 Vercel Functions 로 배포됩니다. 키는 Vercel 프로젝트 → Settings → Environment Variables 에만 넣습니다.

| 변수 | 내용 |
| --- | --- |
| `MOLIT_SERVICE_KEY` | 공공데이터포털 "국토교통부_아파트 매매 실거래가 자료" 인증키 |
| `GEMINI_API_KEYS` | 제미나이 키 여러 개를 쉼표로 구분 (`키1,키2,키3`). 한도를 다 쓴 키는 건너뛰고 다음 키 사용 |
| `GEMINI_MODELS` | (선택) 쉼표로 구분한 모델 순서. 기본값 `gemini-3.1-flash-lite,gemini-3.5-flash-lite,gemini-flash-lite-latest,gemini-3.8-flash` — 한 모델에서 모든 키의 한도가 끝나면 다음 모델 사용 |
| `APP_PASSCODE` | (선택·권장) 접속 암호. 설정하면 앱의 홈 > 설정에 같은 암호를 넣어야 서버 기능이 동작 |

| 주소 | 내용 |
| --- | --- |
| `GET /api/trades?lawd=11440&dong=아현동` | 최근 3개월 아파트 매매 실거래 (직전 거래가 포함) |
| `GET /api/news?q=마포구 부동산` | 최근 7일 지역 뉴스 제목·언론사·링크 |
| `POST /api/ai` | `task`: `briefing`(시장 분석) · `contract`(계약서 사진 정리) · `listings`(매물 정리) |

키가 없거나 조회에 실패하면 브리핑은 샘플 데이터로 표시하고 화면에 이유를 알려 줍니다.
로컬에서는 `.env.local` 에 같은 변수를 넣고 `npm run dev` 하면 `/api` 도 함께 동작합니다.

## 고객용 자료 디자인

카드뉴스(1080×1350)와 맞춤 매물 제안서(1920×1080)는 `src/lib/design.ts` 의 한 가지 디자인 체계로 그립니다.

- 방향: 격식 있는 공문서. 흰 종이, 쪽빛 명조 제목, 표와 가는 괘선, 지적도(필지 경계선) 무늬
- 주홍은 상승(▲)과 작은 표식에만, 파랑은 하락(▼)에만 사용
- 글꼴: 본명조(Noto Serif KR, 앱에 포함) + Pretendard
- 제안서는 어느 기기에서나 똑같이 보이도록 그림으로 만들며, PPT 에는 장마다 전체 화면 그림으로 들어갑니다 (PPT 안에서 글자 수정은 안 됨)

## 네이버 매물 가져오기

서버가 네이버를 자동으로 긁지 않습니다. 사용자가 보고 있는 화면에서 가져옵니다.

- **휴대폰**: 매물 > 가져오기에서 화면 캡처나 복사한 글을 넣으면 AI가 정리합니다.
- **PC**: 매물 > 가져오기의 "매물 수집기"를 크롬 즐겨찾기 막대에 끌어다 놓고, 네이버 부동산에서 누릅니다.
  그 뒤 화면에 새로 뜨는 매물 응답을 모아 `.json` 파일로 저장하고, 그 파일을 앱에서 선택합니다.
  (`src/lib/collector.js` 가 수집기, `src/lib/naverParse.ts` 가 파일 해석)
- **PC 크롬 확장 프로그램** (`extension/`): 시군구 코드와 동 이름을 넣으면 열려 있는 네이버 부동산 창을 찾아(없으면 열어) 그 동 화면으로 이동하고,
  매물 목록을 1.5초 간격으로 넘기며 모읍니다. 요청은 한 번에 최대 200회이고, 네이버가 거절(429 등)하면 재시도 없이 멈춥니다.
  수집이 끝난 뒤 앱 창을 열면 매물이 자동으로 들어옵니다. 설치: 앱의 매물 > 가져오기에서 내려받아 압축을 풀고,
  `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드합니다".
  앱 주소가 `*.vercel.app` 이 아니면 `extension/manifest.json` 의 마지막 `matches` 에 앱 주소를 추가해야 자동 전달이 됩니다.
- **구·동 단위**: 네이버 지역 코드(`cortarNo`, 법정동코드 10자리·앞 5자리는 시군구)를 응답 주소에서 읽어 매물에 붙이고, 동별 필터와 동별 비교표를 보여 줍니다.
- **누적·변동**: 다시 수집하면 이전 기록과 비교해 신규·가격 변동·사라진 매물을 표시합니다.
  마지막 수집 후 3일이 지나거나, 수집해 둔 단지에 새 실거래 신고가 뜨면 다시 수집하라고 알립니다.

## 아직 없는 기능

- 손님이 직접 접속하는 상담 신청 링크, 앱을 닫아도 오는 푸시 알림, 기기 간 데이터 공유 (데이터베이스 필요)
- 전월세 실거래, 아파트 외 유형 실거래

## 구조

- `src/App.tsx` — 하단 메뉴, 종료 확인
- `api/` — 서버 기능 (실거래·뉴스·AI)
- `src/lib/api.ts` — 서버 기능 호출
- `src/lib/nav.ts` — 뒤로가기 규칙 (창·선택 모드 취소 → 이전 화면 → 홈에서 종료 확인)
- `src/lib/cardnews.ts` — 카드뉴스 이미지 생성
- `src/lib/design.ts` — 고객용 자료 디자인 체계
- `src/lib/proposal.ts` — 매물 제안서 생성
- `src/lib/match.ts` — 매물 추천 점수, 계약 일정 계산
- `src/pages/` — 메뉴별 화면

데이터(상담·계약·설정)는 기기 안(localStorage), 계약서 사진은 IndexedDB 에 저장됩니다.
