# 중개사 슈퍼앱 (초안)

공인중개사 사무소 업무를 한곳에서 처리하는 모바일 웹앱(PWA)입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드 (dist/)
```

## 하단 5단 메뉴

| 메뉴 | 내용 | 현재 상태 |
| --- | --- | --- |
| 홈 | 오늘 요약, 바로가기, 다가오는 일정, 사무소 설정 | 동작 |
| 브리핑 | 실거래·뉴스 요약, 카드뉴스 4장(1080×1350 PNG) 생성·저장·공유 | 동작 (데이터는 샘플) |
| 매물 | 지역 매물 필터, 단지별 평균가·면적별 분포 차트 | 동작 (데이터는 샘플) |
| 상담 | 상담 신청서 접수·상태 관리, 맞춤 매물 추천, PPT(.pptx) 생성 | 동작 |
| 계약 | 계약·중도금·잔금 일정(D-day), 진행 단계, 계약서 사진 보관, 알림 | 동작 (AI 분석은 연동 예정) |

## 아직 연동되지 않은 부분 (서버 필요)

- 실거래 자료: 국토교통부 실거래가 공개 API (공공데이터포털 인증키)
- 뉴스 수집·AI 분석, 계약서 사진 AI 분석: AI API 키를 보관할 서버
- 네이버 매물 수집
- 손님이 직접 접속하는 상담 신청 링크, 앱을 닫아도 오는 푸시 알림

샘플 데이터는 `src/data/sample.ts` 에 모여 있어, 연동 시 이 배열만 실제 데이터로 바꾸면 됩니다.

## 구조

- `src/App.tsx` — 하단 메뉴, 종료 확인
- `src/lib/nav.ts` — 뒤로가기 규칙 (창·선택 모드 취소 → 이전 화면 → 홈에서 종료 확인)
- `src/lib/cardnews.ts` — 카드뉴스 이미지 생성
- `src/lib/ppt.ts` — 매물 제안 PPT 생성
- `src/lib/match.ts` — 매물 추천 점수, 계약 일정 계산
- `src/pages/` — 메뉴별 화면

데이터(상담·계약·설정)는 기기 안(localStorage), 계약서 사진은 IndexedDB 에 저장됩니다.
